# Disney Planner v6.1.0 ホームUI設計凍結

## 目的

ホーム画面を情報の一覧ではなく、利用者へ次の行動を案内する入口として再設計する。

## 凍結内容

- 重複していたクイック操作カードを廃止する。
- 現在のパーク、滞在時間、人数、候補数、生成状態は上部カードへ集約する。
- AI案内カードで次の操作を一つだけ提示する。
- 旅行設定、やりたいこと、候補確認、プラン、当日の進捗を表示する。
- 来園設定、選択済み施設、生成済みプランは詳細確認用カードとして残す。
- Web、Windows、スマートフォン幅で情報の優先順位を共通化する。
- 画面全体は縦スクロール可能とし、スクロールバーを常時表示する。

## 変更しないもの

- AppStateの保存形式
- 画面遷移先
- 候補生成処理
- Schedule Engine
- Today画面
