# v6.5.0 設計凍結 — 候補確認スマートフォンUI

## 目的

候補確認画面をスマートフォンの限られた高さで安全に表示し、候補0件時の誤操作とRenderFlex overflowを防止する。

## 凍結仕様

- 候補0件時は検索以外のカテゴリ・フィルター・候補一覧を表示しない。
- 空状態では「やりたいことへ戻る」を主操作とする。
- 共通下部CTAも候補0件時は「やりたいことへ戻る」へ切り替える。
- 画面内の重複したプラン生成フッターは廃止し、共通下部CTAへ一本化する。
- 候補がある場合、概要・カテゴリ・フィルターを上部に置き、候補一覧へ残り高さを割り当てる。
- スマートフォンでは説明と操作ラベルを短縮する。
- Web／Windowsの候補編集機能、優先度、詳細設定、候補削除、プラン生成ロジックは変更しない。
