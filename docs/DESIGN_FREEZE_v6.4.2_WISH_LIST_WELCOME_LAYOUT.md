# v6.4.2 Wish List 開始画面レイアウト設計凍結

## 目的

スマートフォン幅400×611で発生していた下方向のRenderFlex overflowを解消する。

## 凍結仕様

- 開始画面では詳細ステップインジケーターを表示しない。
- 開始画面では質問文、選択案内、AI補足メッセージを重複表示しない。
- 開始画面は対象パーク、進捗バー、AI質問開始カードだけで構成する。
- 詳細ステップインジケーターはAI質問開始後に表示する。
- 狭い幅または低い高さでは余白・アイコン・ボタンをコンパクト化する。
- 質問回答、Wish選択、候補生成ロジックは変更しない。
