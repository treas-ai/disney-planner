# Disney Planner v6.1.1 ホーム動線設計凍結

## 目的

ホーム画面をメニュー一覧ではなく、現在の進行状況と次の行動を案内するナビゲーション画面として統一する。

## 凍結事項

- ホームの主要CTAは固定フッターに一つだけ表示する。
- CTAは進捗に応じて自動的に切り替える。
  1. 希望未選択: AIとプランを作る
  2. 希望選択済み・候補未作成: AI候補を確認
  3. 候補作成済み・プラン未生成: プランを生成・確認
  4. プラン生成済み: 当日の予定を見る
- AI案内カード内には重複するメインボタンを置かない。
- 現在のプランカードは状態表示専用とし、画面遷移を割り当てない。
- 来園設定、候補、生成済みプランのカード内リンクは補助編集導線として残す。
- Web、Windows、スマートフォン幅で同じ動線を維持する。

## 非変更範囲

- 旅行設定、希望選択、候補抽出、プラン生成の内部ロジック
- 保存形式および既存データ
- ナビゲーション先の各画面
