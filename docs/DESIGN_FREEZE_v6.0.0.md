# Disney Planner v6.0.0 Candidate Review UI 設計凍結

## 目的
従来の全施設検索画面を廃止し、質問・やりたいことから抽出済みの候補だけを表示する最終調整画面へ変更する。

## 凍結仕様
- 表示対象は現在のパークに対して抽出済みの候補のみ。
- 4カテゴリ（アトラクション、ショー・パレード、フード・ドリンク、グリーティング）に分ける。
- ユーザーが行う操作は、優先度変更、詳細条件設定、不要候補の削除に限定する。
- 各カード内で既存の詳細設定（時間帯、待ち時間許容、DPA/PP、予約時刻、メモ等）を編集できる。
- 「候補をリセット」で現在パークの候補と施設別設定を削除する。やりたいこと回答は保持する。
- 全施設検索、営業状態フィルター、ランド・シー横断編集は候補レビュー画面から除外する。
- プラン生成前に候補件数と外せない候補件数を表示する。

## 非変更範囲
- 旅行設定
- Wishデータ
- Schedule Engine
- Today画面
- 永続化形式（既存施設選択・PlanPreferenceを継続利用）
