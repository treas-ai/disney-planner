# Opening Transport Strategy

更新日: 2026-08-27

朝一最適化では、待ち時間が短いという理由だけで移動型施設を優先しない。

評価するもの:
- 後回し損失
- 一日を通した通常待機難易度
- 現在待ち時間
- 移動時間
- DPA / PP / Single Rider などの代替手段
- ユーザー優先度
- 移動型施設の乗車地点 / 降車地点

固定ルートの移動型施設は、利用後の現在地を exitAreaId へ更新する。
その移動メリットは次の候補施設への移動コスト低下として自然に評価する。

行先が時間帯等で変わる施設は possibleExitAreaIds を持つ。
行先未確定時は Planner が都合のよい到着地を推測しない。
朝一では不確定性ペナルティを与える。

朝一の目的は「短い待ち時間の施設を多く消化すること」ではなく、
「一日の中で後から処理しづらい体験を、移動を含めて最も価値高く処理すること」。
