# Disney Expert Recommendation Layer

更新日: 2026-08-27

## 目的

Disney Planner を「短い待ち時間を順番に消化するPlanner」ではなく、
「ディズニーに詳しい人が、その来園日に一日の体験価値を最大化するPlanner」へ進化させる。

## 評価思想

Expert Recommendation はハード制約ではなく上位の価値シグナル。
ユーザーの明示希望、営業状況、固定予定、待ち時間、移動、DPA/PP/Single Rider等を破壊しない。

評価軸:
- 体験そのものの価値
- そのパークならではの独自性
- 期間限定・周年・公演回数・予約難度等の希少性
- 一日を通した通常待機難易度
- 後回し損失
- DPA / PP / Single Rider等の代替可能性
- 現在地と移動コスト
- ユーザー優先度

## カテゴリー別

### アトラクション
人気度だけでなく、独自性・通常待機難易度・後回し損失を評価する。
移動型施設は「目的地体験」の点数を抑え、entry/exit locationによるルート価値を別途評価する。

### フード
単なる最寄りレストランではなく、テーマ性、パーク固有性、ショーレストラン、予約希少性を評価する。
ただし高評価店のために一日の移動や固定予定を壊さない。

### ショー・パレード
期間限定、周年、終了間近、抽選/DPA等の取得条件を評価する。
エントリー受付は当選を仮定しない。
公演が希望退園時刻を超える場合は、既存のソフト退園制約で価値と超過コストを比較する。

## データ運用

`assets/master/expert_recommendations.json` に編集可能な推薦シードを保持する。
施設名をScheduleEngineへハードコードしない。
公式情報は開催期間・運営ルールの正とし、編集評価値はあくまで推薦シグナルとして扱う。
