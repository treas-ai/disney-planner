# Wish List Completion Scope

## 自動生成
- アトラクション
- ショー
- パレード
- キャラクターグリーティング

上記は施設マスターを正として、現在プランへ追加可能な施設だけ表示します。

## 公式メニュー収録方針
- 現在販売中のおすすめ・限定メニュー
- 特徴的な店舗限定ドリンク
- フリードリンク対象候補のスープ・スペシャルドリンク
- 夏季フード・デザート
- 一般的なコーラ、お茶、通常コーヒーは除外

## 表示しないもの
- 販売前
- 販売終了後
- 休止・終了した施設
- 過去イベント
- 将来イベント
- アルコールをフリードリンク対象として扱うこと
