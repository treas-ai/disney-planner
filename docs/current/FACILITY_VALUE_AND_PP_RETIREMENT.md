# Facility Value Scoring / Priority Pass retirement

- First Move = wait-time saving + base experience value + active content value.
- Highest-priority destination attractions receive a stronger base value.
- Events, special drinks, limited menus, goods and souvenirs raise venue value.
- Limited-time content receives an urgency bonus.
- Priority Pass is removed from active planning.
- DPA remains the active paid-pass strategy.
- PP-only facilities are NOT falsely converted into DPA facilities.
- When wait history is missing, DPA is not used as a penalty.
- Legacy PP fields remain internally only for backward compatibility.
