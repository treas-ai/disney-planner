# Disney Planner v6.3.0 旅行設定UI 設計凍結

## 目的
旅行設定を、上から順に入力すればAIプラン作成に必要な条件が揃う構成へ整理する。

## 凍結内容
- 最上部に設定ガイドを表示する。
- 基本項目は「パーク」「来園時間・人数」「食事」の順に表示する。
- 利用サービスには初心者にも分かる説明を付ける。
- バケーションパッケージ特典はON時のみ表示する。
- 雨天・子ども連れ・ライブデータ取得元は「詳細設定」へ格納する。
- 更新情報・バックアップ・共有・初回案内は「データ管理・その他」へ格納する。
- 詳細設定とデータ管理は初期状態で折りたたむ。
- Web/Windowsは2列、スマートフォンは1列とする。
- スクロールが必要な場合はスクロールバーを常時表示する。
- 設定値、保存処理、Controllerの公開APIは変更しない。

## 対象外
- 初心者モード本体
- 来園日の追加
- TripSettingsのデータモデル変更
- ライブデータ取得機能の変更
