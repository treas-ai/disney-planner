# Disney Planner v6.4.7 設計凍結

## 目的

AI質問の複数選択中に、画面下部の候補確認CTAを誤って押す操作を防止する。

## 凍結仕様

- AI質問が完了するまでは画面下部CTAを無効化する。
- 無効時の文言は「質問を完了してください」とする。
- 複数選択中は質問カード内の「選択内容を確定して次へ」を唯一の有効な主操作とする。
- AI質問完了後は「プラン候補を確認」を有効化する。
- 「一覧から選ぶ」モードでは候補確認への導線を有効化する。
- 回答内容、Wish選択、候補生成ロジックは変更しない。

## 変更ファイル

- `lib/app/main_shell.dart`
- `lib/features/wish_list/wish_list_screen.dart`
- `pubspec.yaml`
- `CHANGELOG.md`
