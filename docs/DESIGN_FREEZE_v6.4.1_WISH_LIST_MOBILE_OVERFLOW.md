# Disney Planner v6.4.1 設計凍結

## 対象
Wish List「AI質問」開始画面のスマートフォン表示。

## 問題
400×611相当の表示領域で、開始カードが下方向へ21pxオーバーフローしていた。

## 凍結仕様
- 高さが小さい場合は開始カードを自動的にコンパクト表示する。
- アイコン、余白、説明文、ボタン高を段階的に縮小する。
- 通常の高さではv6.4.0の情報量を維持する。
- 内容が収まらない場合に備え、開始カードを縦スクロール可能にする。
- スクロール領域には常時表示スクロールバーを付ける。
- 質問回答、候補生成、Wish選択ロジックは変更しない。
