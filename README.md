# Disney Planner

東京ディズニーリゾート向けのプランニングアプリです。

Flutterで開発しており、アトラクション・レストラン・ショーなどを自由に組み合わせて、自分だけのプランを作成できます。

## 主な機能

- 施設一覧表示
- カテゴリによる絞り込み
- エリアによる絞り込み
- 営業状態による絞り込み
- 施設検索
- 並び替え
- プラン作成
- 選択施設の優先順位設定
- SharedPreferencesによるデータ保存

## 開発環境

- Flutter
- Dart
- Material 3

## 対応パーク

- 東京ディズニーランド
- 東京ディズニーシー
