# Disney Planner

Disney Planner は、東京ディズニーリゾートを中心に、来園者の希望・過去待ち時間・公演時刻・DPA 等の利用条件・移動時間・食事・休憩をまとめて評価し、実行可能な1日のプランを生成する Flutter アプリです。

## 現在の開発方針

現在の設計では、ユーザーが「待てる時間」を低・中・高や30分などの固定基準で決める方式を主判断にしません。

プランナー自身が収集済みデータから各候補の価値とコストを評価します。

主な評価対象:

- 来園日の時間帯別予測待ち時間
- 同一施設の別時間帯と比較した待ち時間差
- その時間に利用することによる時間節約
- 施設の体験時間
- 現在地・前後施設からの移動時間
- エリア移動によるロス
- DPA / PP / エントリー受付 / ショー等の時間制約
- 食事・休憩・固定予定
- 閉園・退園予定までの残り時間
- データのサンプル件数・信頼性

## 設計凍結: Data-driven Schedule Optimization

### 基本原則

プラン生成は「待ち時間が短い順」ではなく、1日の総コストを評価して行います。

```text
候補施設
  ↓
時間帯別待ち時間を取得
  ↓
移動時間を算出
  ↓
体験時間・準備時間を加算
  ↓
固定予定・公演・食事との競合を確認
  ↓
別時間帯へ回した場合との差を評価
  ↓
DPA等を使った場合の節約量を評価
  ↓
1日全体の実行可能性を比較
  ↓
最も価値の高い組み合わせを採用
```

### 時間コスト

各候補は少なくとも次の時間を一体で扱います。

```text
totalCost =
  movementMinutes
  + waitMinutes
  + experienceMinutes
  + requiredBufferMinutes
```

「待ち時間20分だから得」という判定は禁止します。
遠いエリアへ移動するために20分必要なら、その移動もコストです。

### 待ち時間評価

収集済み待ち時間プロファイルを優先して使用します。

固定の「30分までなら許容」のような基準は、プラン生成の主判断から外します。
データが存在する場合は、施設ごとの通常水準・時間帯差・後続時間帯との差を使って相対評価します。

データが不足する場合だけ、安全側のフォールバックを使用し、その事実を理由へ明記します。

### 移動評価

施設単体ではなく、前後の予定との連続性を評価します。

同じエリアまたは近接エリアを連続させることを基本とし、待ち時間を数分節約するためだけにパークを横断するプランは避けます。

ただし、固定時刻、公演、DPA、極端な待ち時間差など、移動コストを上回る利益がある場合は例外とします。

### DPA評価

DPA は単純な人気順ではなく、購入によって節約できる実時間と1日全体への効果で評価します。

```text
DPA value =
  standbyCost
  - dpaCost
  + scheduleBenefit
```

アトラクションDPAを「使わない」とした場合も、通常待機候補は同じデータ駆動評価を行います。

### ショー・パレード

公式の日付別公演データを固定時刻制約として扱います。

エントリー受付対象公演は未当選を当選扱いしません。
通常鑑賞可能な公演は、鑑賞場所への移動・事前待機・公演時間・退場を含めて評価します。

希望退園時刻は原則として尊重しますが、完全なハード制約にはしません。
希望退園を越える候補は、施設名や公演名を特別扱いせず、候補価値と退園超過コストを分相当の連続値で比較します。
Step 1 ではこの汎用評価を公式公演候補へ接続し、価値が超過コストを上回る場合のみ実効退園時刻を延長します。

### 時間精度

内部計算は1分単位で保持し、計算途中では丸めません。
表示・確定予定は5分単位へ切り上げます。

## 品質基準

変更後はプロジェクトルートで次を実行します。

```powershell
.\verify.ps1
```

合格条件:

```text
flutter analyze: No issues found
flutter test: All tests passed
```

`verify.ps1` は検証終了後、プロジェクトルートに残った一時 ZIP を削除します。

## 設計変更ルール

このデータ駆動型プラン生成方針を設計凍結します。

実装中に別案が出ても、その場で基本方針を変更せずバックログへ記録し、次の設計改訂時に評価します。


## Disney Expert Recommendation Layer

AIプランは待ち時間だけでなく、体験価値・パーク固有性・希少性・後回し損失・代替サービス・移動を統合して評価します。
編集可能な推薦シードは `assets/master/expert_recommendations.json`、設計方針は `docs/current/DISNEY_EXPERT_RECOMMENDATION_LAYER.md` を参照してください。
